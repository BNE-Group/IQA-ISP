# ISP Image Quality Assessment Toolkit

## Introduction
This repo focuses on the specific image quality generated by ISP.
Different from general IQA methods, this tool provides fine-grained indicators for ISP assessment.

This repo is implemented by PyTorch in a **differentible** style. You can use it as a loss function and optimize your ISP.

## Demo
``python main.py``

You can easily get an IQA report by running this code.

## Details
This repo provides two kinds of IQA metrics:

### General IQA
- **PSNR**: Peak signal-to-noise ratio.
- **SSIM**: Structural similarity.
- **LPIPS**: Learned perceptual similarity.

### ISP-Specified IQA
#### Details
- **Blocking**: Quantify blocking artifacts by measuring discontinuities at block boundaries.
- **Shadow Details**: Quantify shadow detail preservation in an image.
- **Sharpness**: Compute image sharpness using the Tenengrad method.
- **Texture Preservation**: Quantify texture preservation using local standard deviation in patches.
- **Watercolor**: Detect "watercolor" or "plastic skin" artifacts caused by over-smoothing.


#### Color
- **DeltaE**: Compute CIEDE2000 color difference (ΔE00) between two RGB images.
- **Fringing**:  Detect purple fringing artifacts in an image.
- **Colorfulness**: Estimate perceptual colorfulness using CIELAB color space.

#### Noise
- **Chroma Noise**: Estimate chrominance noise level in an image.
- **Luma Noise**: Estimate luminance noise level using local variance.
- **Local Variance Noise**: Estimate luminance noise level using local variance.

#### Light
- **Effective Dynamic Rance**: Estimate Effective Dynamic Range (EDR) in Exposure Values (EV) using SNR criterion.
